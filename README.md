# 산경모아

인천대학교 산업경영공학과 학생을 위한 **비공식 정보 허브 초안**입니다.

## 구성

- 공식 학사·졸업·장학·대회·취업 정보 연결, 검색과 분야별 필터
- 브라우저에만 저장되는 정보 책갈피와 학기 체크리스트
- 대회·취업 준비 편집 가이드와 경험 기록 양식 내려받기
- 전공·진로 기초 길잡이, 모바일 화면, 키보드 탐색

현재 개별 공고 자동 수집, 회원가입, 서버 저장, 온라인 기고 제출은 없습니다. 준비 가이드는 실제 선배 후기가 아닙니다.

## 수정할 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 화면 구성과 기본 문구 |
| `styles.css` | 색상·크기·모바일 디자인 |
| `data.js` | 공식 정보 링크, 편집 가이드, 분야 안내 |
| `app.js` | 검색·필터·저장·화면 전환 |

일반 콘텐츠를 바꾸려면 `data.js`에서 해당 제목·설명·링크를 수정하세요. `checked`는 실제 연결 경로를 확인한 날로 갱신합니다. 모집 상태나 마감을 확인한 날짜라는 뜻이 아닙니다.

공개 확정된 자료만 저장하세요. 공개 저장소는 변경 이력도 공개됩니다. 인터뷰 원본, 기고자 연락처, 공개 동의 전 초안은 이 저장소에 넣지 않습니다.

## GitHub Pages

별도 패키지 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 사이트입니다.

1. 파일을 `main` 브랜치에 올립니다.
2. GitHub 저장소의 **Settings → Pages**를 엽니다.
3. **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**를 선택하고 저장합니다.
4. 배포 후 `https://blue-sky-sailboat.github.io/`에서 확인합니다.

`.nojekyll` 파일이 포함되어 있습니다. 자체 서버·데이터베이스·유료 API는 사용하지 않습니다. 글꼴은 Google Fonts에서 불러오며 연결되지 않으면 시스템 글꼴로 표시합니다.

## 운영 시작 전

- 운영용 비공개 연락 경로를 정해 기고 안내에 반영합니다.
- 실제 경험 글은 작성자 확인과 공개 동의를 받은 뒤 등록합니다.
- 공지 자동 수집은 출처 접근 방식·운영 조건을 확인한 다음 도입합니다.
- 학과 공식 승인 전에는 학생 운영임을 명확하게 표시합니다.

## 확인

JavaScript 문법 점검: `node --check app.js`, `node --check data.js`.

모바일·PC에서 검색, 분야 필터, 저장/해제, 새로고침 후 저장 유지, 체크리스트, 가이드 창 닫기, 양식 내려받기를 확인합니다.
